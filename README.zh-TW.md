# Care for You（宜室宜家）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

一款可以放在工作視窗旁的居家照料遊戲。家裡的人、寵物和植物各有自己的作息。有人想喝水、想聊幾句，或想有人陪伴時，你可以暫停手邊的事照料一下，再回去做自己的事。遊戲不計分，照料不及也沒有懲罰。

## 遊玩

[在瀏覽器遊玩](https://careforyou.dev/?lang=zh-TW)。在本機用瀏覽器開啟 `frontend/index.html` 即可執行。
