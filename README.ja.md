# Care for You（宜室宜家）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

作業のかたわらで、家にいる人やペット、植物の世話をするブラウザーゲームです。水が欲しい、少し話したい、そばにいてほしい。そんな声に応えたら、また自分の作業に戻れます。スコアや失敗によるペナルティはありません。

## 遊び方

[ブラウザーで遊ぶ](https://careforyou.dev/?lang=ja)。手元で遊ぶ場合は、ブラウザーで `frontend/index.html` を開きます。
