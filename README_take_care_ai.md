# Care You

一个需要你照看的人，不定时出现在你的桌面上，打断你的工作。可以是爷爷奶奶、爸爸妈妈、宝宝，也可以是一只猫。没有分数，照看本身就是全部体验。

## 当前状态

原型 v0：单个网页，随机打断，限时回应，问话类事件把回答写入记忆，偶尔有不带理由的小心意。数据只保存在浏览器本地。

## 运行

直接用浏览器打开 `prototype/index.html`。想让它悬浮在其他窗口之上，用桌面版 Chrome 或 Edge，点页面里的"浮动小窗"。

## 目录

- prototype：原型代码
- 内部设计、讨论和调研记录不在本仓库，在另外的内部文档目录

## 数据与隐私

记忆只写在本机浏览器的 localStorage，不上传。
