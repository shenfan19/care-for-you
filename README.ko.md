# Care for You（宜室宜家）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

일을 하다가 잠시 멈춰 집에 있는 사람과 반려동물, 식물을 돌보는 브라우저 게임입니다. 누군가 물을 마시고 싶거나 이야기를 나누고 싶을 때 잠깐 챙겨 주고 다시 하던 일로 돌아갈 수 있습니다. 점수나 실패에 따른 불이익은 없습니다.

## 플레이

[브라우저에서 플레이](https://careforyou.dev/?lang=ko). 로컬에서 실행하려면 브라우저에서 frontend/index.html을 엽니다.
