# Care for You（宜室宜家）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

一款可以放在工作窗口旁边的居家照料游戏。家里的人、宠物和植物各有自己的作息。有人想喝水、想聊两句，或想有人陪伴时，你可以停下手头的事照看一下，再回去做自己的事。游戏没有分数和失败惩罚。

## 游玩

[在浏览器游玩](https://careforyou.dev/?lang=zh-CN)。在本地用浏览器打开 `frontend/index.html` 即可运行。
